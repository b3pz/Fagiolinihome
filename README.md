# Fagiolini V11 — Native Family Edition

Release UX/UI completa basata sulla V10 stabile.

## Principi
- stessa logica dati/Supabase/Telegram della base stabile
- interfaccia soft-native: meno box, più sezioni continue e leggibili
- mobile-first con testi grandi, navigazione compatta
- desktop landscape reale
- dark mode ad alto contrasto

## Novità V11
- Home senza hero fotografico gigante: apre subito sui riepiloghi utili
- banner compleanno dinamico soltanto nel giorno del compleanno di un membro della famiglia
- Calendario ridisegnato: griglia più elegante, weekend evidenziati, oggi/selection più chiari
- Diario bambini centrale: pappa/latte, sonno, pannolino, cacca, bagnetto, medicine, crescita e note
- Diario retroattivo: data e ora sempre modificabili; si può aggiungere oggi una voce di ieri
- Storico bambini modificabile ed eliminabile
- Timeline giornaliera e riepilogo 7/30 giorni
- Pasti più morbidi e continui, un giorno alla volta; ricettario famiglia mantenuto
- Bank mantenuta semplice con dettagli a livelli
- Casa/Auto/Salute/Organizza mantengono le funzioni esistenti con design system più morbido
- Tema Chiaro/Scuro/Sistema mantenuto

## Vincoli preservati
- Lavatrice → Asciugatrice
- Spazzare → Lavare pavimenti
- sessione 3 ore
- calendario cliccabile e creazione evento dalla data
- ferie/smart working/malattia, calcetto, compleanni, rifiuti, Telegram
